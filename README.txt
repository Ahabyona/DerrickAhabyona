GITHUB PAGES UPLOAD STEPS
1. Open https://github.com/Ahabyona/Derrick-Ahabyona
2. Click Add file > Upload files.
3. Upload index.html, style.css, research.html, projects.html, cv.html from this folder (not the ZIP unless extracted).
4. Choose Commit changes. Replace existing index.html if GitHub prompts or edit it directly.
5. Your existing Pages setting (main / root) can stay unchanged.
6. Your website address: https://ahabyona.github.io/Derrick-Ahabyona/
7. Change YOUR_EMAIL@example.com in every HTML file to your actual email.
8. Add a profile photo later by uploading portrait.jpg and replacing <div class="avatar">DA</div> with <img class="avatar" src="portrait.jpg" alt="Portrait of Derrick Ahabyona">.
9. Upload cv.pdf later if you want to make your CV downloadable.
